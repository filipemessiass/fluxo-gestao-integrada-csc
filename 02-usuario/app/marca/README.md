# Identidade FLUXO

Referência oficial: prancha de marca fornecida na solicitação de 26/10/2026. A marca combina traços azuis em forma de caminho, nós dourados e o nome FLUXO em azul-marinho, com destaque dourado no X. O símbolo foi recriado em SVG para permanecer nítido em diferentes tamanhos.

| Ativo | Uso |
| --- | --- |
| `fluxo-logo.svg` | Marca horizontal em fundo claro. |
| `fluxo-logo-light.svg` | Marca horizontal em fundo escuro. |
| `fluxo-icon.svg` | Símbolo isolado no menu e no Início. |
| `fluxo-favicon.svg` | Favicon das páginas. |

Os SVGs anteriores (`fluxo-horizontal-*`, `fluxo-simbolo-*`, `fluxo-app.svg` e `favicon.svg`) foram mantidos por compatibilidade com eventuais referências externas. As páginas ativas usam os arquivos da tabela.

O design system fica em `../fluxo.css`. As cores principais são azul-marinho `#101E30`, azul `#3265AF` e dourado `#E6BC79`. A interface mantém temas claro, escuro e automático, com a marca aplicada em ambos.

As capturas reais atualizadas ficam em `capturas/` e o registro de validação em `VALIDACAO-2026-10-26.md`.
